# Student Groups Workspace UI Design

## Goal

Make `/distribution/groups` easier to scan and operate without changing registration behavior or permissions.

## Approved design

- Keep group monitoring as the page's primary workspace.
- Move flexible subgroup planning into a modal opened by a clear button.
- Replace the duplicated cycle pills and summary card with one cycle workspace header.
- Show the selected cycle's status and key counts before secondary actions.
- Keep destructive and infrequent actions visually secondary.
- Preserve every existing workflow, permission check, Arabic label, and English label.
- Keep the layout usable on mobile and desktop.

## Information hierarchy

1. Page title and global actions.
2. Current cycle selector and compact operational summary.
3. Main groups and their subgroups.
4. Planning and administrative tools in dialogs.
